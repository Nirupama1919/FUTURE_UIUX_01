# SmileCare Clinic Website Redesign

## Project Overview
This project is a UI/UX redesign of a local dental clinic website focused on improving lead generation and user experience.

## Pages Designed
- Homepage
- Service Page
- Contact Page
- Mobile Responsive Screens

## Tools Used
- Figma
- Iconify
- Google Fonts

## UX Goals
- Improve trust and credibility
- Increase appointment bookings
- Create responsive design
- Improve navigation and CTA visibility
